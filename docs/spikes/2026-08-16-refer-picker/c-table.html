Refer — the table, shrunk

The picker IS the table: same four columns, same badge hues, same golden cursor, and / opens the filter exactly as it does in the main view. It opens on the tree's own default, state:*active*. One row is being picked, so there is no mark gutter and no multi-select.

@ link — pick a row
C-u @ relation — kind first, then the row
n p move · j k and arrows too
/ filter · RET choose · ESC out one step
A bare @ fires only at a WORD BOUNDARY. Select a region first and @ turns it into the link, its own words becoming what the link reads as and seeding the filter.
