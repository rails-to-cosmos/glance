* Glance

Serves an org tree as a keyboard-driven table in a browser tab and writes back
into the files by span splice. Org files stay the single source of truth: one
walk into an in-memory projection, a websocket streaming every change as the
file watch re-parses, and every write replacing the exact characters a headline
occupies — optimistic lock, temp-plus-rename, every other byte identical.
Underneath sits =Data.Org=, a megaparsec org-mode grammar where every element
carries a half-open character span into its document.

** Quickstart

#+begin_src sh
cabal run glance -- serve   --dir ~/org     # http://127.0.0.1:7777/
cabal run glance -- desktop --dir ~/org     # same daemon, app window
make native                                 # build the WebKitGTK window in
#+end_src

=serve= takes =--dir=, =--port= (7777), =--assets PATH=, =--include-derived=;
=desktop= adds =--browser CMD=, =--dry-run=, =--keep-serving=. Binds
=127.0.0.1= only, and binds *before* the ~10 s walk — store routes answer 503
with a loading body until it lands, so the page paints an indexing state and
polls out of it.

#+begin_src sh
curl -s localhost:7777/headlines | jq '.rows | length'
curl -s 'localhost:7777/headlines?q=tag:work%20sort:deadline&limit=100' | jq '.sort'
#+end_src

** Queries, by example

One string states both the narrowing and the order ([[https://github.com/rails-to-cosmos/table-view][table-view]]'s grammar,
ported term for term; divergences enumerated in [[file:docs/invariants.md][docs/invariants.md]]).

| query                               | rows served                                  |
|-------------------------------------+----------------------------------------------|
| =milk=                              | substring anywhere in the row                |
| =state:TODO=                        | exactly that keyword                         |
| =state:TODO\vert{}DONE=             | either (alternatives OR)                     |
| =tag:work tag:home=                 | both tags (tokens AND)                       |
| =-tag:work=                         | rows without the tag                         |
| =tag:*empty*=                       | untagged rows (=*word*= is a meta, never text) |
| =state:*active*=                    | active keywords + stateless — the default view |
| =tag:*archive*=                     | the archived rows every other query hides    |
| =-planned:*empty* sort:scheduled=   | the agenda: dated rows, earliest first       |
| =ref:ROW-ID=                        | rows whose subtree links to that row (=@= drills) |
| =sort:state->title:desc=            | order by cycle, ties by title reversed       |
| =sort:*none*=                       | document order, no sort at all               |

Written order is precedence; a query naming any =sort:= replaces the default
chain (state · title · deadline · scheduled, state in the tree's own =#+TODO:=
order). =:work:= and ~=code=~ stay text — only column keys, =planned=, =ref=
and =sort= are predicates.

** Keys, the dozen that matter

The keymap is data (=Glance.Web.Keymap=): the served page's last line is the
whole map, and the echo pill names every press =SEQ → command=. Letters bind
the *physical key*, so =т з о л= navigates on a Cyrillic layout.

| =n= =p= / =f= =b= | rows / cells — and in the document, siblings / grain    |
| =RET=             | materialize the row; in the document, edit the element  |
| =DEL=             | the ladder: unmark, else drop a query token, else pop a drill |
| =t= =:= =d d= =D= | state palette · tag popup · flag-then-archive           |
| =m= =u= =M= =U=   | dired's marks                                           |
| =o=               | follow the row's links (one opens, several list)        |
| =+=               | capture · =g= default view · =P= pin view as default · =a= agenda |
| =@=               | drill into referring rows; =DEL= walks back             |
| =/=               | filter palette · =,= settings · =C-x C-s= sync the sheet |

** Capture

=+= is one form: a tag field completing over the tree's vocabulary, the
template's own fields grown in place when the tag settles, the line last. RET
moves forward and captures; empty tag = plain inbox line; ESC leaves whole.

A tag's template is the first heading of its config layer:

#+begin_src org
# .org-glance/config/tags/book.org
#+TODO: TODO READING | READ
* Book
:PROPERTIES:
:AUTHOR: %^{Author}
:END:
%?
#+end_src

=%?= is where the typed line lands, =%^{Author}= becomes a form field, =%U= /
=%T= stamp the server's clock; anything else copies through verbatim. A tagged
capture mints a real org-glance blob — id, shard path, =EXTERNAL.jsonl= note —
that Emacs adopts on its next refresh.

** The material document

=RET= opens the row's subtree as a document + property panel. Movement is the
table's two axes: =n=/=p= walk siblings at the current grain — a list, block
or table is *one* stop, so holding =n= skims — and =f=/=b= go a grain finer /
broader (a composite's items, a headline's cells). Every element commits on
its own (=C-x C-s= / =C-c C-c=), =RET= on a child drills in, =DEL= walks out,
a moved file is a 409 the sheet waits on. =ORG_GLANCE_ID=, the creation stamp
and the =:LOGBOOK:= drawer are server-preserved — shown or hidden, never
round-tripped through the client.

** Commands

=POST /command {name, id | ids, args, digests?}= — ids group by file, one
drift-locked atomic write per file, per-id answers. Refusals are 400 with
nothing written.

| name           | args                             | writes                            |
|----------------+----------------------------------+-----------------------------------|
| =set-state=    | ={keyword}=, nullable            | the keyword span                  |
| =set-priority= | ={priority}=, nullable           | org's =[#A]= token                |
| =set-title=    | ={title}=                        | the title span alone              |
| =set-planning= | ={keyword, date}=, date nullable | one =SCHEDULED=/=DEADLINE= entry  |
| =add-tag= / =remove-tag= | ={tag}=                | the tag on / off                  |
| =rename-tag=   | ={from, to}=                     | both ends, one write per file     |
| =archive=      | ={}=                             | =add-tag ARCHIVE=; idempotent     |
| =capture=      | ={text, tag?, fields?}=          | a headline, or a store blob       |
| =edit-link=    | ={span, target, desc?}=          | one link's own range              |

#+begin_src sh
curl -s -X POST -H 'content-type: application/json' localhost:7777/command \
     -d '{"name": "set-state", "ids": ["ROW-ID"], "args": {"keyword": "DONE"}}'
curl -s -X POST -H 'content-type: application/json' localhost:7777/command \
     -d '{"name": "capture", "args": {"text": "TODO Dune", "tag": "book",
                                      "fields": {"Author": "Herbert"}}}'
#+end_src

The route never writes the store; rows come back over the file watch.

** Config

Org files under =<root>/.org-glance/config/=, never a row source:

#+begin_src org
# .org-glance/config/system.org — the tree-wide layer
#+TODO: TODO STARTED | DONE CANCELLED
#+GLANCE_DEFAULT_FILTER: state:*active* -tag:someday
#+GLANCE_CAPTURE_TARGET: inbox.org
#+end_src

=tags/TAG.org= adds a per-tag cycle (and a capture template, above).
Recognition unions every layer; classification is widest-scope
(built-in > system > tags > file), so a file redeclaring =TODO= cannot make it
done-like. The settings sheet (=,=) edits the layers; the default view is
pinned from the table with =P= and shown read-only there.

** org-glance interop

Reads and writes the same tree Emacs's org-glance does: walks the canonical
=data/= store, declines the derived =overviews/=, =meta/= and =occurrences/=
(=--include-derived= turns that off), resolves shared ids in the store's
favour. Every daemon write into a blob appends to =meta/EXTERNAL.jsonl=, which
=M-x org-glance-graph:refresh-external= folds back. =glance scan= reads
org-glance's index read-only and reports drift. Details: [[file:docs/invariants.md][docs/invariants.md]]
(Scan, Walk).

** Build and verify

Components: =glance-internal= (parser), public =glance= (=Glance.Query=),
=glance-web=, =glance-desktop-native=, one CLI, one suite. =glance.cabal= is
hand-maintained — no hpack.

#+begin_src sh
cabal build all                      # no GTK anywhere
cabal test                           # the suite
GLANCE_CORPUS=~/sync cabal test      # plus corpus-sampled groups (they SAY when skipped)
cabal run -v0 glance -- scan ~/sync  # the parser oracle: expect 0 span violations
make native                          # WebKitGTK window: vendored/ + GIR path, -f native-window
make sync-renderer                   # refresh assets/table-view.js from ../table-view/web
#+end_src

Standing oracle over =~/sync=, 2026-08-04: 6292 files, 12611 headlines, *0
span violations*, walk ~10 s. =assets/table-view.js= is a committed build
input compiled into the binary; =--assets ../table-view/web= serves the
sibling checkout live for renderer hacking. =vendored/= exists because Arch
ships WebKit2 4.1 typelibs only — =cabal get NAME-VERSION && diff -r= shows
the whole patch.
